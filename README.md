# Ayush Raj Portfolio

A responsive React, TypeScript, and Vite portfolio, ready to deploy on Vercel.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Contact

The contact section provides direct email, phone, and LinkedIn links.

## Deploy to Vercel

Import this repository into Vercel. The included `vercel.json` sets the Vite build command and `dist` output.
